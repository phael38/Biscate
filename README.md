# Biscate

Site de tarefas com painel, convites e levantamentos. Neste momento o saldo é simulado (guardado no browser de cada visitante) e nada é pago.

## Publicar no GitHub Pages (sem programar)

1. Entra em github.com e cria uma conta, se ainda não tiveres.
2. Clica em **New repository**. Nome: `biscate`. Deixa-o **Public** (o GitHub Pages gratuito exige repositório público). Clica em **Create repository**.
3. Na página do repositório, clica em **uploading an existing file**, arrasta o ficheiro `index.html` e clica em **Commit changes**.
4. Vai a **Settings > Pages**. Em **Source** escolhe **Deploy from a branch**, branch **main**, pasta **/ (root)**, e clica em **Save**.
5. Espera 1 a 2 minutos. O site fica em `https://O-TEU-UTILIZADOR.github.io/biscate/`.

Os links de convite passam a usar esse endereço automaticamente.

## Importante

- O código fica público. Não escrevas aqui chaves nem senhas.
- O saldo vive no browser de cada pessoa, por isso não é seguro nem pago. Para saldo protegido e pagamentos reais é preciso um servidor com login (por exemplo Supabase ou Firebase).
