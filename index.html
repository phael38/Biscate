Perguntas frequentes

O dinheiro é real?

Ainda não. Os dólares são de demonstração e não podem ser levantados a sério. Quando houver pagamentos reais, o site vai avisar de forma clara.

Onde ficam os meus dados?

Neste momento, só no teu browser. Nada é enviado para servidores.

Como é calculado o que ganho?

Cada tarefa mostra o valor antes de começares. Os valores vão de US$ 0,30 a US$ 1,00, conforme o esforço.

Posso usar no telemóvel?

Sim, o site adapta-se ao tamanho do ecrã.

Como funcionam os convites?

Cada amigo que entra com o teu link rende US$ 1,00 ao teu saldo. Neste momento os convites são simulados, tal como o resto do saldo.

Pronto para experimentar?

Começa agora e faz a tua primeira tarefa em menos de um minuto.
